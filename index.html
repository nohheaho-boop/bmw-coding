💡 자주 묻는 질문 (FAQ)

Q. 차량 보증(BSI)에 문제가 생기나요?
안전이 검증된 기능만 활성화하며, 공식 센터의 차량 보증(AS)에 문제 되는 부분이나 고장 위험이 있는 모듈은 일체 건드리지 않으니 안심하셔도 됩니다.
Q. 출장 지역과 비용은 어떻게 되나요?
제가 계신 곳으로 방문 시 코딩 8만원이며, 고객님 계신 곳으로 출장을 원하실 경우 거리에 따라 소정의 출장비가 추가됩니다. 상세 비용은 문의 시 안내해 드립니다.
Q. 내 차도 코딩/업데이트가 가능할까요?
아래 연식 및 운영체제 호환표를 참고해 주세요. 같은 연식이라도 옵션에 따라 다를 수 있으므로 차대번호로 정확한 조회가 필요합니다.

코딩 기능 설명 - BMW/MINI 상세 항목

DriveOne에서 세팅해 드리는 21가지 주요 코딩 항목입니다. 항목을 터치하면 상세한 설명이 나타납니다.

1. 도어 열림 상태에서 원터치 윈도우 활성화
도어가 열린 상태에서도 창문 스위치를 한 번만 당기면 창문이 끝까지 닫히거나 열리도록 편리하게 설정합니다.

2. 후진 시 사이드 미러 각도(틸트) 변경
후진 기어(R) 인가 시 조수석 사이드 미러가 바닥을 향해 과하게 꺾이는 현상을 방지하고, 운전자 시야에 딱 맞는 각도(10~100%)로 부드럽게 조절합니다.

3. 후방 카메라 트레일러 모드 활성화
후방 카메라 화면에 수직 탑뷰(줌) 모드를 추가하여 견인고리 체결이나 정밀한 주차를 돕습니다.

4. 트렁크 원터치 닫힘 및 알림음 활성화
실내 버튼이나 스마트키 버튼을 원터치로 눌러 트렁크를 닫을 수 있으며, 트렁크가 닫힐 때 안전을 위한 경고 알림음을 발생시킵니다.

5. TPMS 타이어 압력/온도 활성화
타이어 공기압 모니터링 시스템(TPMS) 화면에 타이어의 정확한 수치(PSI)와 온도 정보를 상세하게 표시합니다.

6. 시스템 시간 자동 동기화 활성화
차량 설정 메뉴에 '자동 시간 동기화' 체크박스를 생성하여 시계를 매번 수동으로 맞출 필요 없게 만들어 줍니다.

7. GPS 기반 시간 오차 보정
온라인 및 GPS 위성 신호를 기반으로 차량 시스템 시간을 실시간 동기화하여 항상 단 1초의 오차도 없이 정확하게 유지합니다.

8. 시동 시 교통 주의 문구 비활성화
시동을 켤 때마다 화면에 표시되어 확인 버튼을 눌러야 했던 성가신 안전 경고 문구를 완전히 삭제하여 즉시 홈 화면으로 진입합니다.

9. 웰컴라이트 헤드라이트/안개등 점등
스마트키로 도어 잠금 해제 시, 차량을 환영해 주는 웰컴라이트와 함께 전면 헤드라이트와 안개등도 동시에 켜져 주변을 화려하고 밝게 비춰줍니다.

10. 스마트폰 벨소리 차량 스피커 동시 출력
차량 블루투스 연결 시 기본 내장 벨소리 대신, 내 스마트폰에 설정해 둔 벨소리가 차량 스피커를 통해 그대로 웅장하게 울리도록 설정합니다.

11. 전조등 OFF 버튼 기능 활성화
라이트 다이얼이 오토(AUTO)에 고정되어 있을 때에도, 스위치의 'OFF' 버튼을 눌러 강제로 전면 라이트를 소등할 수 있게 합니다.

12. 주간 주행등(데이라이트) ON/OFF 메뉴
차량 설정의 외부 조명 메뉴에 '주간 주행등' 항목을 추가하여 차박이나 정차 등 필요에 따라 데이라이트를 완전히 끄거나 켤 수 있게 합니다.

13. 리어 테일램프 상시 점등 활성화
주간에도 후면 테일램프(미등)가 상시로 점등되도록 설정하여 드레스업 효과는 물론 주간 주행 안전성을 대폭 높여줍니다.

14. 시동 중 문 잠금 시 클락션 2회 비활성화
시동이 켜진 채로 스마트키를 소지하고 내려 문을 잠글 때, 시끄럽게 '빵빵' 울려 당황스럽게 만들었던 클락션 소리를 조용히 소거합니다.

15. 원터치 방향지시등 5회 변경
방향지시등 레버를 가볍게 터치했을 때 깜빡이는 기본 3회를 5회로 늘려, 고속도로나 차선 변경 시 뒷차에 충분한 신호를 줄 수 있도록 돕습니다.

16. 재난 문자 알림 비활성화
주행 중 불쑥 나타나 내비게이션 화면 전체를 가리는 긴급 재난 문자 알림 팝업창이 뜨지 않도록 깔끔하게 차단합니다.

17. USB 동영상 재생 기능 활성화
단순한 음악 파일을 넘어, 차량의 USB 포트를 통해 영화나 뮤직비디오 같은 동영상 파일도 화면에서 선명하게 재생할 수 있도록 시스템을 오픈합니다.

18. USB 동영상 모든 코덱 활성화
USB로 동영상을 시청할 때 '지원하지 않는 형식'이라는 오류가 뜨지 않도록 차량 디스플레이가 지원하는 모든 비디오/오디오 코덱의 제한을 해제합니다.

19. iDrive 주행락 해제 (비디오 인 모션)
차량이 주행을 시작하면 안전을 위해 끊기던 영상(DMB, USB 영상, 미러링 등)이 속도와 상관없이 계속 재생되도록 속도 락을 완벽히 해제합니다. (동승자용)

20. 레인 센서 감도 조절 기능
오토 와이퍼 작동 시 빗물을 감지하는 센서의 민감도를 iDrive 디스플레이 메뉴 안에서 훨씬 디테일하게 직접 조절할 수 있습니다.

21. 차선 변경 어시스트 활성화
고속도로 주행 보조(크루즈 컨트롤) 작동 상태에서 운전자가 방향지시등 레버를 켜면, 차량이 안전을 스스로 확인하고 부드럽게 차선을 변경해 줍니다.
